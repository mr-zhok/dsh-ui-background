# DSH UI Background

> 给 DSH Web UI 加一个本地背景图库：壁纸 / 浮层两种模式、320px 缩略图、暗化遮罩、按秒/分钟自动轮换。
>
> A local background gallery for the DSH Web UI.

**当前版本：1.8.1** · 适用于 DSH Desktop / DSH Web（支持 Bundle Patch 与 Client Module）

> 个人项目，主要在 DSH Desktop 上测试；DSH 升级后如果 Bundle API 有变化，可能需要适配。

---

## 简介

DSH UI Background 是一个 DSH Web UI 插件。它在「设置 → UI设置」里维护一个最多 **10 张**的本地图库，选任意一张作为界面背景，并提供：

- **壁纸模式**：图片垫在界面下方，面板半透明；
- **浮层模式**：图片盖在界面上方，按浓度叠加；
- **缩略图**：图库只加载 320px 小图，背景始终使用原图；
- **暗化遮罩**：壁纸模式下压暗背景，提升文字可读性；
- **自动轮换**：按秒/分钟切换图库，顺序或随机；
- **快捷键**：默认 `Alt+C`，一键去除背景，可换绑或清除。

所有图片和设置都保存在本机，不上传云端，也没有遥测。

---

## 功能

| 功能 | 说明 |
|---|---|
| 本地图库 | 最多 **10 张**，按图片内容去重；重复上传只会切换，不会新增 |
| 上传 / 切换 / 删除 | 支持 PNG、JPEG、WebP、GIF，单张 ≤ 12 MB；点击缩略图切换，右上角 × 删除 |
| 缩略图 | 上传时生成 320px WebP 小图；旧图首次打开图库时自动生成并回存 |
| 刷新图库 | 扫描 `images/` 目录，把手工放入的图片纳入索引；自动重命名、去重、保留最新 10 张 |
| 两种显示方式 | **壁纸**：图片在界面下方；**浮层**：图片在界面上方 |
| 独立浓度 | 壁纸的「界面透明度」和浮层的「图片浓度」各自保存，切换不互相污染 |
| 暗化遮罩 | 仅壁纸模式；0–100% 压暗图片，0% 关闭 |
| 轮换背景 | 按秒/分钟自动切换；顺序/随机；间隔 0 关闭，最小 10 秒 |
| 启用开关 | 关闭后保留图库和设置，只是不显示 |
| 快捷键 | 默认 `Alt+C`，可换绑/清除；一键把两种模式的浓度归零 |
| 明暗主题 | 面板与按钮使用 DSH 主题 token，适配深色/浅色主题 |
| 持久化 | 图片与设置保存在 `$DSH_HOME/ui-background/`，重装插件、重启 DSH 都不丢 |

设置页从上到下依次是：背景图、显示方式、浓度、暗化遮罩（仅壁纸）、轮换背景、启用背景、去除背景快捷键。

## 环境要求

- **DSH Desktop** 或带 Web UI 的 **DSH Web**；
- 现代 Chromium 内核浏览器（DSH Desktop 自带）。

> 插件只在 DSH 的 Web UI 中显示；headless 等无 UI 的形态不会出现设置页。

---

## 安装

这是一个 **DSH 本地 Bundle**，不是 npm 包，不需要 `npm install`。

1. 从 GitHub Releases 下载 `zhang-dsh-ui-background-<version>.tgz`；
2. 打开 DSH 的插件管理 / Bundle 安装入口，选择「安装本地 Bundle」；
3. 选中下载的 `.tgz`，确认安装；
4. 刷新页面。如果插件没有出现，或仍是旧版本，**重启 DSH**。

> 不同 DSH 版本的插件管理入口名称可能不同；核心是安装本地 Bundle 的 `.tgz`。

---

## 编译 / 打包

从源码打包需要 Node.js + pnpm。插件没有构建步骤，`pnpm pack` 只负责生成可安装的 Bundle：

```bash
git clone https://github.com/mr-zhok/dsh-ui-background.git
cd dsh-ui-background
pnpm pack
```

会生成 `zhang-dsh-ui-background-<version>.tgz`，再按上面的「安装」步骤安装。

## 使用

1. 打开 **设置 → UI设置**；
2. 点击「添加图片」选图，或把图片放进 `$DSH_HOME/ui-background/images/` 后点「刷新图库」；
3. 点击缩略图切换当前背景，点右上角 × 删除；
4. 在「显示方式」里选择壁纸或浮层，按需调整浓度；
5. 壁纸模式可调「暗化遮罩」；
6. 需要自动换图时，在「轮换背景」里填间隔（0 = 关闭）；
7. 需要快速去掉背景时，按当前快捷键（默认 `Alt+C`）。

### 显示方式

**壁纸模式（默认）**

- 图片在界面下方，面板通过主题 token 变成半透明；
- 「界面透明度」越大，面板越透明、壁纸越明显；0% 恢复不透明界面；
- 适合喜欢背景一直可见、又不想影响文字可读性的场景。

**浮层模式**

- 图片以固定层盖在界面上方，鼠标事件穿透；
- 「图片浓度」直接控制图片强度；
- 浓度过高会降低文字对比度，建议按需调低。

两种模式的浓度分别保存。切换模式不会覆盖另一种模式的设置。

### 暗化遮罩

- 仅壁纸模式显示；
- 0–100%：在壁纸上方叠一层黑色渐变，压暗图片；
- 不改变面板透明度，也不修改原图；0% 时完全不生成遮罩层；
- 适合图片较亮、细节较多，文字对比度不够的情况。

### 轮换背景

- 间隔 `0` = 关闭；
- 最小 **10 秒**；单位支持秒/分钟；
- 顺序：按图库顺序循环；
- 随机：每次随机选一张，避免连续重复当前图；
- 设置页关闭后仍会继续轮换；
- 「启用背景」关闭、只有 1 张图、页面切到后台时暂停；
- 手动点击缩略图会重置倒计时；
- 目前按**单窗口**实现；多窗口会各自计时，未做跨窗口加锁。

### 快捷键

- 默认 `Alt+C`，全局生效；
- 作用：把两种模式的浓度同时归零，立即生效并持久化；
- 支持「修改」重新录制，以及「清除」禁用；
- 录制时至少需要一个修饰键（`F1`–`F24` 除外）；
- 快捷键是全局的，输入框内也会触发；建议避免 `Ctrl+C`、`Ctrl+V` 等常用组合。

## 数据与隐私

所有数据都保存在 `$DSH_HOME/ui-background/`（Windows 为 `%DSH_HOME%\ui-background\`）：

- 图片原图、320px 缩略图、图库索引和显示设置；
- 只在本机，不会上传到任何服务器，也没有遥测；
- 背景渲染始终使用**原图**，不做压缩、裁剪或重新编码；
- 缩略图只用于图库预览，不参与背景渲染；
- 图库和设置在所有 profile / workspace 之间共享（当前设计）。

---

## 已知限制

- **图片数量**：最多 10 张，单张 ≤ 12 MB；
- **GIF**：缩略图只取第一帧，背景仍保留动图；
- **旧图缩略图**：较早版本或手工放入的图片没有缩略图，首次打开图库会下载一次原图生成小图，之后只加载小图；
- **单窗口轮换**：多窗口会各自计时；
- **壁纸主题依赖**：壁纸模式依赖 DSH 的主题颜色，自定义主题可能出现色差；
- **浮层可读性**：浓度过高会降低文字对比度；
- **刷新 IO**：刷新图库会读取并哈希 `images/` 下每张图，图片较多/较大时会有一次 IO/CPU 峰值；
- **全局图库**：所有 profile / workspace 共用同一份数据，没有按会话/工作区隔离。
