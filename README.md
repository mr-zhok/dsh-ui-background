# DSH UI Background

给 DSH Web UI 加一个本地背景图库：壁纸 / 浮层两种模式、320px 缩略图、暗化遮罩、按秒/分钟自动轮换、可换绑的去除背景快捷键。

**当前版本：1.12.0** · 适用于 DSH Desktop / DSH Web（Bundle Patch + Client Module）

> 个人项目，主要在 DSH Desktop 上测试；DSH 升级后 Bundle API 若有变化可能需要适配。

## 功能

| 功能 | 说明 |
|---|---|
| 本地图库 | 最多 **10 张**，按内容去重；重复上传只切换不新增 |
| 上传 / 切换 / 删除 | PNG、JPEG、WebP、GIF，单张 ≤ 12 MB；点缩略图切换，右上角 × 删除 |
| 删除确认与撤销 | 删除前弹出确认框；删除后 10 秒内可撤销，图片和它在图库中的位置一并恢复；撤销非当前背景图不会切换背景 |
| 拖拽排序 | 拖动缩略图调整顺序，顺序持久化，刷新图库后保留 |
| 缩略图 | 上传时生成 320px WebP；旧图首次打开图库时自动生成并回存，背景始终用原图 |
| 两种显示方式 | **壁纸**：图片在界面下方、面板半透明；**浮层**：图片盖在界面上方、按浓度叠加 |
| 独立浓度 | 壁纸「界面透明度」与浮层「图片浓度」分别保存，互不影响 |
| 暗化遮罩 | 仅壁纸模式，0–100% 压暗背景，0% 关闭 |
| 轮换背景 | 按秒/分钟自动切换，顺序/随机，间隔 0 关闭，最小 10 秒 |
| 切换淡入 | 换图时旧图 480ms 淡出到新图，不再硬切 |
| 快捷键 | 默认 `Alt+C`，一键把两种模式浓度归零，可换绑/清除 |
| 持久化 | 图片与设置存在 `$DSH_HOME/ui-background/`，重装插件、重启 DSH 都不丢 |

设置页顺序：背景图 → 显示方式 → 浓度 → 暗化遮罩（仅壁纸）→ 轮换背景 → 启用背景 → 去除背景快捷键。

## 环境要求

- DSH Desktop，或带 Web UI 的 DSH Web；
- 现代 Chromium 内核浏览器（DSH Desktop 自带）。

> 插件只在 DSH 的 Web UI 中显示；headless 等无 UI 形态不会出现设置页。

## 安装

这是 **DSH 本地 Bundle**，不是 npm 包，不需要 `npm install`。

1. 从 [GitHub Releases](https://github.com/mr-zhok/dsh-ui-background/releases) 下载 `zhang-dsh-ui-background-<version>.tgz`；
2. 打开 DSH 的插件管理 / Bundle 安装入口，选择「安装本地 Bundle」；
3. 选中 `.tgz` 确认安装；
4. 刷新页面；如果没出现或仍是旧版本，**重启 DSH**。

> 不同 DSH 版本的入口名称可能不同，核心是安装本地 Bundle 的 `.tgz`。

## 使用

1. 打开 **设置 → UI设置**；
2. 点「添加图片」选图，或把图片放进 `$DSH_HOME/ui-background/images/` 后点「刷新图库」；
3. 点缩略图切换，拖动缩略图排序，点右上角 × 删除；
4. 选「壁纸」或「浮层」，按需调浓度；壁纸模式可加暗化遮罩；
5. 需要自动换图时填轮换间隔（0 = 关闭）；
6. 需要快速去掉背景时按快捷键（默认 `Alt+C`）。

**显示方式**：壁纸模式靠主题 token 把面板变半透明，「界面透明度」越大壁纸越明显，0% 恢复不透明；浮层模式是鼠标穿透的固定层，「图片浓度」过高会降低文字对比度。

**轮换**：设置页关闭后仍继续；「启用背景」关闭、只有 1 张图、页面切到后台时暂停；手动点缩略图会重置倒计时；按单窗口实现，多窗口各自计时。

**快捷键**：全局生效（输入框内也会触发），录制时需要至少一个修饰键（`F1`–`F24` 除外）；建议避开 `Ctrl+C`、`Ctrl+V` 等常用组合。

## 数据与隐私

所有数据都在 `$DSH_HOME/ui-background/`（Windows 为 `%DSH_HOME%\ui-background\`）：

- 原图、320px 缩略图、索引与显示设置，只在本机，不上传、无遥测；
- 背景渲染始终使用**原图**，不压缩、不裁剪、不重新编码；缩略图只用于图库预览；
- 整个目录复制即可备份/换机；
- 当前为**全局一份**，所有 profile / workspace 共享同一套图库和设置。

## 已知限制

- 最多 10 张图，单张 ≤ 12 MB；GIF 缩略图只取第一帧，背景仍是动图；
- 删除有二次确认和 10 秒撤销窗口，但撤销依赖原图字节，超大图或读取失败时无法撤销；
- 拖拽排序只支持鼠标；
- 壁纸模式依赖 DSH 主题颜色，自定义主题可能出现色差；
- 「刷新图库」会读取并哈希 `images/` 下每张图，图片多时有一次 IO/CPU 峰值；
- 多窗口轮换各自计时，拖拽排序以最后写入为准。

## 从源码打包

插件没有构建步骤，`pnpm pack` 只生成可安装的 Bundle：

```bash
git clone https://github.com/mr-zhok/dsh-ui-background.git
cd dsh-ui-background
pnpm pack
```
